> **学习骨架（先记结构，再记细节）**  
> **① 概念**（量/率、基期现期）→ **② 速算**（怎么算得快）→ **③ 公式**（考什么套哪条）→ **④ 题型**（增长/比重/倍数…）→ **⑤ 易错**（读材料坑）

## 一、基本概念

### 1.1 量与率（按呈现形式）

|       | 含义                       | 例子         |
| ----- | ------------------------ | ---------- |
| **量** | 有一定计量单位的绝对数，**有单位**      | 吨、kg、m²、亿元 |
| **率** | 两个相关的数在一定条件下的比值，**没有单位** | %、成、倍      |

### 1.2 基期与现期（按研究内容）

| 词       | 含义             |
| ------- | -------------- |
| **基期**  | 比较时作为参照标准的时期   |
| **现期**  | 与基期相比较的时期      |
| **基期值** | 描述基期的具体数值      |
| **现期值** | 描述现期的具体数值      |
| **增长量** | 现期值相对基期值增长的量   |
| **增长率** | 现期值相对基期值增长的百分比 |

### 1.3 同比 / 环比 / 百分点 ★易混

| 说法 | 比什么 | 注意 |
|------|--------|------|
| **同比** | 与上年同期比 | 常比「金额」或「增速」 |
| **环比** | 与上一统计期比 | 月环比、季环比 |
| **百分点** | 两个百分数相减 | 12.4%−15.0%=下降 **2.6 个百分点** |

**坑：「增长 12.4%」和「同比下降 2.6 个百分点」不矛盾**

- 「比上年增长 12.4%」→ 比的是**金额**，还在涨；
- 「同比下降 2.6 个百分点」→ 比的是**增速**，涨得更慢（去年约 15.0%，今年 12.4%）。

## 二、速算工具

### 2.1 有效数字保留规则（总纲）★

| 运算     | 截几位      | 说明                               |
| ------ | -------- | -------------------------------- |
| **乘法** | **2 位**  | 两位×两位，结果量级靠估算卡住                  |
| **除法** | **3 位**  | 分子分母各留 3 位有效数字                   |
| **加法** | **3 位**  | 末位对齐，留 3 位有效数字                   |
| **减法** | **一般不截** | 相减会放大误差，直接精算；量级差很大时大数不动、只把小数量级补上 |

**两个配套动作：**

1. **四舍五入 + 同向截**：分子分母各自四舍五入，方向保持一致（都舍或都入），误差可以抵消一部分。  
   （**直接截断**只用于比大小，如差分法；算具体数值一律四舍五入。）

**截几位还要看选项差距**：首位不同 → 2 位够；首位相同第二位不同 → 3 位；前两位都相同 → 4 位或精算。

**选项差得远截得短，挨得近留得长。误差方向（用来卡选项）：**

| 截法        | 结果 |
| --------- | -- |
| 分子变小、分母变大 | 偏小 |
| 分子变大、分母变小 | 偏大 |

**两个坑：**

- 只截分母不截分子 → 误差全堆在分子上，反而更偏。
- 该 3 位却截 2 位，且选项首两位相同 → 算完两个选项重合，只能猜。

### 2.2 截位直除（最常用）

$$
\frac{48562}{123478}\approx\frac{486}{1234}\approx 0.39
$$

### 2.3 百化分（必背）

| 百分数                | 分数             | 百分数               | 分数        |
| ------------------ | -------------- | ----------------- | --------- |
| 16.7% / 14.3%      | 1/6、1/7        | 12.5% / 11.1%≈11% | 1/8、1/9   |
| 6.7% / 6.25%       | 1/15、1/16      | 9.1%≈9% / 8.3%    | 1/11、1/12 |
| 5.9% / 5.6% / 5.3% | 1/17、1/18、1/19 | 7.7% / 7.1%       | 1/13、1/14 |

> **连号一起背**：1/17、1/18、1/19 对应 5.9%、5.6%、5.3%，分母每加 1，百分数约掉 0.3 个百分点；**个位越大、百分数越小**。

现期 480、增速 25% → 基期：

$$
\frac{480}{1+\frac{1}{4}}=480\times\frac{4}{5}=384
$$

### 2.4 修正法 ★

**凑整修正**改数字是为了**算得快**，**差分法**改数字是为了**比得准**。一个求值、一个比大小，别混用。

#### （1）凑整修正（为了好除）

分母先加减成好约分的数，分子按同一比例同向修正。

| 操作   | 商会 | 分子怎么修 |
| ---- | -- | ----- |
| 分母加大 | 偏小 | 也加大   |
| 分母减小 | 偏大 | 也减小   |

**例 1**：求 4876÷1985

1. 分母 1985 凑成 **2000**（改动 0.75%）；
2. 分子同向加：4876×0.75%≈37 → 4913；
3. 4913÷2000=2.4565。

**例 2**：求 3560÷812 → 分母凑 **800**，分子同向减约 53 → 3507÷800=4.384。

**修正量**：分子 × 改动比例（改动一般 <2%）。

**两个要求**：分母凑成整千/整百/整十；改动幅度别超 2%。

#### （2）差分法（两分数很接近时比大小）★

**用来干什么**：比较两个分数大小。分子都大、分母也都大，截位也分不出时用。

**差分怎么造**：大分数 − 小分数，**分子减分子，分母减分母**。

**三步走：**

1. 粗判谁大，记「大分数 / 小分数」；
2. 造出差分数；
3. **用差分数去和小分数比**（差分数只替代大分数）。

| 比较结果          | 结论                |
| ------------- | ----------------- |
| 差分数 **>** 小分数 | 大分数 **更大**（原方向不变） |
| 差分数 **<** 小分数 | 小分数 **更大**（方向反转）  |

**例**：比较 583/4720 与 619/5060

差分数 = 36/340≈0.106，小分数≈0.124 → 差分数更小 → **方向反转** → 583/4720 更大。

**注意**：只有「分子大、分母也大」才用；差分数必须更好算才划算。

### 2.5 心算乘法

| 技巧                     | 例                                      |
| ---------------------- | -------------------------------------- |
| 5 结尾平方：前位×(前位+1)，后接 25 | 65²=4225                            |
| ×11：两数相加插中间（满 10 进位）   | 86×11=946                       |
| 5 结尾相乘：拆出 2 凑整十        | 15×16=30×8                 |
| 百分数拆分                  | ×35.8%≈×(33.3%+2.5%) |
| ×1.1 / ×0.9；高位先乘       | 对齐选项量级                                 |

估算顺序：先加减 → 再乘 → 再除。

### 2.6 比较方法解题思维 ★

#### （1）加减法（A ± B）

1. 数据较小、较整或为百分数 → 直接算完再比。
2. 数据较大 → 算前几位有效数字再比。

#### （2）除法（A / B）

先看特点，能直接比就不算：

- 分母相同 → **分子大**的大
- 分子相同 → **分母小**的大
- 分子分母**反向变化** → **分子大**的大
- 再看倍数 / 变化幅度；仍咬死 → 上 **差分法**

#### （3）乘除混合（增长量）

比较 A×q/(1+q) 与 B×q/(1+q)：

1. **现期大且增速也大** → 增量大，不用算；
2. **一大一小时** → 分母倍数不足 1.5 倍时，直接比 A×q 与 B×q。

## 三、核心公式一览

| 名称   | 公式                       | 怎么算                   |
| ---- | ------------------------ | --------------------- |
| 基期   | B=A/(1+q)        | 百化分 / 截位              |
| 现期   | A=B×(1+q)         | 百化分乘法                 |
| 增长量  | G=A×q/(1+q) | **n+1 法则**            |
| 增长率  | q=(现−基)/基 = 增长量/基 | 截位直除                  |
| 比重   | 部分/整体          | 截位直除                  |
| 比重增长量 | Δ=(A/B)×(qA−qB)/(1+qA) | 先定方向，再卡 \|Δ\|<\|qA−qB\| |
| 是几倍  | A/B            | 「多几倍」再减 1             |
| 平均数  | 总量/个数          | 人均、亩产、日均等             |
| 平均数增长率 | (qA−qB)/(1+qB) | qA 总量增速、qB 份数增速 |
| 平均数增长量 | 现期平均数×(qA−qB)/(1+qA) | 和比重增量同一套路 |
| 贡献率  | A增量/B增量        | 单位 %     |
| 拉动增长 | A增量/B基期        | 单位：**百分点**               |

## 四、题型精讲

### 4.1 基期 / 现期 / 增长率

- 基期：除以 (1+q)；**降幅**除以 (1−\|q\|)
- 增长率：截位直除 (现−基)/基

### 4.2 增长量（含 n+1）★高频

当 q≈1/n：

$$
G\approx\frac{A}{n+1}
$$

**一般式**（q≈n/m）：

$$
G=A\times\frac{n}{m+n}
$$

例：24.8%≈1/4 → 6485×24.8%/(1+24.8%) ≈ 6485/5

记住：q 变大，q/(1+q) 变大；且 q/(1+q)=1−1/(1+q)

**比较大小**：现期大且增速大 → 往往增量大；一大一小时比 q/(1+q)（分母倍数不足 1.5 倍时直接比 A×q）。

### 4.3 比重

**两期比重差（精确式）★**：部分现期 A、增速 qA；整体现期 B、增速 qB。

$$
\Delta=\frac{A}{B}\times\frac{q_A-q_B}{1+q_A}\quad(百分点)
$$

**两步锁定选项：**

1. **先定方向**：qA>qB 升，qA<qB 降；
2. **再卡大小**：\|Δ\| 一定 **小于 \|qA−qB\| 个百分点**；
3. 还分不出：Δ 略小于 \|qA−qB\|，选项偏大时选偏小的。

### 4.4 倍数 / 平均数

- **是几倍** = A/B；**多几倍** = 是几倍 − 1
- **平均数** = 总量/个数
- **平均数增长率** = (qA−qB)/(1+qB)
- **平均数增长量** = 现期平均数 × (qA−qB)/(1+qA)

### 4.5 贡献率 vs 拉动

|      | 分子   | 分母       | 单位  |
| ---- | ---- | -------- | --- |
| 贡献率  | A 增量 | B **增量** | %   |
| 拉动增长 | A 增量 | B **基期** | 百分点 |

### 4.6 混合增速 / 隔年增长

- **混合增速**：介于两边之间，靠近**基期量大**的一边
- **隔年**（不能直接把两个增速相加）：

$$
(1+q_1)(1+q_2)-1\approx q_1+q_2+q_1q_2
$$

### 4.7 特征比例（粗估）

可用 A/B 代替 A/(B±a)；增长率、比重中的 A/(B+A) 可先用 A/B 粗算。

**替代比大小（保序）★**：比较 A1/(A2±A1) 与 B1/(B2±B1) 时，直接改比 A1/A2 与 B1/B2——顺序不变。

## 五、概念积累（材料冷门词）★

| 概念 | 公式 | 易错提醒 |
|------|------|----------|
| 产销比 | **销量** ÷ 产量 | 分子是销量，别写反 |
| 行业亏损面 | 亏损企业数 ÷ 总企业数 | 是「家数」之比，不是亏损额之比 |
| 营业利润率 | 利润 ÷ 营业收入 | 分母是收入，不是成本 |
| 人口增长率 | 人口出生率 − 人口死亡率 | 是两个「率」相减 |
| 周转量 | （人口/货物总数）× 周转距离 | 是**乘法** |
| 总资产 | 所有者权益 **+** 负债 | 是加法 |
| 在校生人数 | 去年在校生 − 毕业 + 招生 | 流水账式递推 |

## 六、读材料与易错清单

**读材料先盯**：时间单位、口径（全国/某省）、注释、同比/环比。

| 易错        | 记住             |
| --------- | -------------- |
| 多几倍 / 是几倍 | 多几倍要减 1        |
| 增长了 / 增长到 | 「了」=增幅；「到」=达到  |
| 百分点 / %   | 比重差、拉动、增速回落用百分点 |
| 增速回落 / 负增长 | 回落=涨得慢；负增长=金额在降 |
| 贡献率 / 拉动  | 增量÷增量 vs 增量÷基期 |
| 隔年增速      | 连乘，不是直接相加      |
| 局部当全年     | 前三季度 ≠ 全年      |
