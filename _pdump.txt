判断推理 · 速记笔记
含两部分：形式逻辑（必然性推理） + 可能性推理·削弱。 形式逻辑原则：翻译 → 定类型 → 套规则 → 只选「一定能推出」。
〇、做题流程（形式逻辑）
翻译：自然语言 →「所有/有些」「且」「或」「→」
定类型：直言 / 联言 / 选言 / 假言 / 三段论
套规则：找矛盾、等价、必然推出；三段论优先画圈
排除：否前、肯后、有些互推、两「有些」硬推 → 一律不选「一定」
一、四类命题一张表

二、直言命题
形式：所有 / 某个 / 有些　A　是 / 非　B
找矛盾（两步同时改）
量词：所有 ↔ 有些
肯否：是 ↔ 非

能推 / 不能推
所有 → 某个 → 有些     ✅ 可向下推
有些 ↛ 某个 ↛ 所有     ❌ 不可向上推
有些是 ≠ 有些非         ❌ 不能互推
三、联言命题（且）

例：「又高又帅」假；已知「高」真 → 「帅」必假。
四、选言命题（或）

例：「考公或考研」真；没考公 → 必考研。
「要么…要么…」= 不相容选言（恰有一个），与默认「或」不同。
五、假言命题 ★重点
主公式（必背）
p → q  ＝  非q → 非p
（原命题 ＝ 逆否命题）
易错：不是「非 p → 非 q」（否前，推不出）。
能推 / 不能推（以下雨 → 地湿 为例）

口诀：顺着箭头可以推；逆着箭头不行。否定结果可以；否定条件不行。
矛盾
p → q 的矛盾 = p 且 非 q（有前件、无后件）。
六、三段论 ★重点
两个前提 + 一个结论，问能否必然推出。
1. 一句话
能不能通过中间那个概念当桥，推出第三句。
所有土木生 → 工科生
小明 → 土木生
⇒ 小明 → 工科生     ✅ 桥（土木生）接上了
桥稳 → 能推；桥对不齐 → 推不出。
2. 优先画圈

怎么画都对 → 选「一定推出」
有的对、有的不对 → 推不出
3. 考试 4 条硬规则
两个「有些」→ 一律推不出
「有些」推不出「所有」
两个「不是」推不出「是」
「所有 A 是 B + 某人是 A」→ 某人是 B（最常见能推）
4. 例题
能推
所有土木生都是工科生；小明是土木生 → 小明是工科生。
推不出
有些土木生是党员；有些党员会英语 → 推不出「有些土木生会英语」。
5. 做题 3 步
翻译成「所有 / 有些 / 某个 + 是/不是」
画圈：有没有第二种合理画法？
见两个「有些」或「有些→所有」→ 直接排除
6. 补充：周延（可后背）
周延＝话说到了这一类的全部。「中项至少周延一次」＝桥至少被说全过一次。
口诀：桥要接牢；有些推不出所有；两否不得肯定；两特称推不出。
七、常见削弱方式总结 ★重点（可能性推理）
削弱题：削弱「论证力度」，不是找绝对矛盾。先看结论属于哪一类。
总表（对照课件）

1. 因果关系类（结论：A 导致 B）

另有他因 / 根本原因：都在说「不全是（或不主要是）A 导致 B」。 有因无果 / 无因有果：用反例拆「A 与 B 总一起」的关系。
2. 缺桥类（论据 AB，结论 AC）
论据只建立了 A 与 B，结论却跳到 A 与 C → 中间缺 B→C 这座桥。
削弱：切断联系＝说明 B 与 C 无关 / B 推不出 C。
3. 做题顺序
找结论：是「A 导致 B」，还是论据讲 B、结论跳到 C？
对号入座：因果五招 / 缺桥切断
选「最能削弱」：直接拆因果或拆桥的，优先于无关项
